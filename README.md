# Velclub — by PSK

Самостоятельная статическая копия виртуального тура с семью панорамами.

Главная страница: `index.html`. Исходная структура и адрес `velclub.html` сохранены.
Все используемые панорамы, плитки, скрипты, видео и музыка находятся в репозитории.
Видимый логотип заменён на `by PSK` по запросу владельца репозитория.

Источник переноса: https://paevskiydesign.ru/3d_tour/velclub/velclub.html
Тур создан в Panotour Pro / krpano. Сторонние компоненты и медиа сохраняют права своих правообладателей.
